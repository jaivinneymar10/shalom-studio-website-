# Shalom Studio - PRIVATE admin copy
DO NOT upload this folder to GitHub. Keep it on your computer only.
(It contains the admin login code. Only upload the public site files.)

HOW TO EDIT
1. Open index.html in Chrome, then add #admin to the address (index.html#admin).
2. Enter your admin password.
3. Tabs: Banner & Hero (incl. hero side photos) | Brand & About | Offers | Reviews |
   Products | Photos | Contact (phone, Instagram, address, legal, analytics)
4. Click "Save & Publish", then "Export JSON" to get site-data.json.
5. Upload site-data.json to GitHub (next to index.html in the PUBLIC site).

BEFORE YOU GO LIVE - CHECKLIST
[ ] Contact tab: real WhatsApp number (country code + digits, e.g. 919XXXXXXXXX)
[ ] Contact tab: real Instagram handle, address, hours, Google Maps link
[ ] Contact tab: Google Drive upload link (replace YOUR_FOLDER_ID) + WhatsApp Channel link
[ ] Reviews tab: delete sample reviews, add real ones + Google Form feedback link
[ ] Brand & About tab: make sure "5000+ Happy Customers" etc. are true
[ ] sitemap.xml and robots.txt: replace YOUR-DOMAIN with your real domain
[ ] Add og:image / og:url / canonical tags (needs your real domain)
[ ] Put your photos in the img/ folder (see img/PUT-PHOTOS-HERE.txt)
